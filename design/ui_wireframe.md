# K_Calculator UI Wireframe - Voice Edition

## Description
The UI features a modern, dark theme with rounded buttons and integrated voice controls.
- **Top Section (Header)**: Contains a big Microphone button (🎤). Next to it is a status text showing "Listening..." / "Speaking..." and a transcript of what the user said. The mic pulses with a CSS animation when listening.
- **Display Screen**: Shows the previous operand/operation and current operand.
- **Bottom Section**: A grid of standard calculator buttons.
- **Footer**: Text displaying "K_Calculator - Voice Enabled | Kobby".
